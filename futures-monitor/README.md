# 豆类期货监控

独立小工具，盯 **豆一 / 豆粕 / 菜粕 2701**，并对照 **美豆、美豆粕、美豆油** 外盘，给出今晚夜盘偏涨还是偏回吐的判断。

不依赖第三方库，系统自带 Python 3 即可。

## 运行

```bash
cd ~/Documents/crypto-code/futures-monitor
python3 monitor.py --once      # 拉一次
python3 monitor.py             # 终端每 3 秒刷新
python3 monitor.py --web       # 浏览器看板，自动打开 http://127.0.0.1:8765
python3 monitor.py --web --notify
```

`--notify` 会在美豆波动超过 8 美分、美豆粕超过 3 美元，或国内合约涨跌超过 1.5% 时发 macOS 通知。

## 看什么

| 板块 | 合约 | 来源 |
|---|---|---|
| 国内 | 豆一2701、豆粕2701、菜粕2701 | 新浪 `nf_A2701` / `nf_M2701` / `nf_RM2701` |
| 外盘 | 美豆、美豆粕、美豆油 | 新浪 `hf_S` / `hf_SM` / `hf_BO` |

夜盘判断规则（简版）：

- 美豆相对昨收 ≥ 8 美分：偏涨；≤ -8 美分：偏跌
- 美豆粕 ±3 美元作为加减分
- 日盘已经大涨、外盘没有新高度：夜盘倾向回吐
- 菜粕盘子更薄，日盘涨得多时回吐权重更高
- 豆一跟东北现货，夜盘最钝

这是监控和启发式提示，不是下单建议。行情来自公开免费接口，可能延迟数秒。
