# 新模型训练注意点（2026-10-28）

现役五个品种的模型和每晚 20:30 的训练先不动。这份只约束下一版模型怎么取数。
换月日历本身见 `换月日历.md`。

## 1. 换月跳空：取数时绕开，不要改价格

`training_dataset/main_minute/` 和 `sina_daily/` 都是不复权拼接。换月那天，新合约价格接在旧合约后面，跳空留在序列里。`roll_calendar/` 已经记下每天跟的是哪个合约，但现役特征计算还没有查它。

下一版跨日比较必须先查日历。当天合约和前一交易日不同，就改用**新合约自己的昨天**，不要用主连上的前一天。

| 要改的量 | 现役算法（含跳空） | 下一版 |
|---|---|---|
| 昨涨跌 | 主连今收 / 主连昨收 | 新合约今收 / 新合约昨收 |
| 日线的量变化、仓变化 | 主连日线前后两天相除 | 新合约自己的前后两天 |
| 分钟的持仓变化 `oi_chg`、成交量变化 `vol_chg` | 主连 14:50 截断的前后两天 | 同上，截断口径不变，参照物换成新合约自己的昨天 |

历史参照在 `data/tushare_min/<品种>/<合约>.csv`，把该合约当天和前一交易日的分钟聚成日线再比。当天实盘、tushare 还没出时，用新浪单合约日线（`getDailyKLine?symbol=合约`）。

下面这些不要改，它们本来就在同一个合约内部：

- 日盘、夜盘、价仓
- 振幅、位置
- 任何只用当天分钟算的收益率、波动率

标签先保持现状：分钟模型是「今天 14:55 → 明天 14:55」，换月日的跳空等于真实换仓盈亏。特征去掉假跳空，标签仍记真实盈亏。不要为了训练去复权整条价格序列。

豆二 2016–2017 年一天只有几手，日历里有来回换月。那几年要么丢掉，要么不要用豆二的跨日特征。2020 年以后的换月是单向的。

成交量为 0、持仓为 0、最高等于最低、开盘或收盘超出最高最低的日线，读入训练时丢掉（`train.bar_ok`）。外盘只有价格的序列不套这条。分钟线当天成交量或 14:50 持仓为 0 的日子同样不进分钟样本。缺了就跳过，不把量变化填成 0。

## 2. 现役模型不要跟着改

五个品种（豆一、豆二、豆粕、菜粕、豆油）的日线回归、日线树、分钟回归、分钟树，以及 `特征.json` 里的配菜，维持 2026-10-22 的定案。新取数规则只用于新训练的模型。

树是 LightGBM 二分类。回归是逻辑回归。综合规则和平仓（只反向平）也先照旧。

## 3. 数据下界和各品种能用到哪天

训练不要读 2016-10-01 之前的数据。`core/train.py` 的 `DATA_FLOOR` 会挡日线读取，更早的日线在 `archive/pre-2016-10/`。

| 数据 | 能用的起点 |
|---|---|
| 八个品种新浪日线、主连分钟、换月日历 | 2016-10-10 左右；花生 2021-02-01 |
| 美豆、美豆粕、美豆油 | 2016-10-27 |
| 马棕油 FCPO | 2020-01-06，只给棕榈油用，现役豆系特征不要读 |
| CFTC 大豆、豆粕、豆油 | 2016-01-05 |
| CFTC 油菜籽 CANOLA | 2018-08-07，只给菜粕、菜籽油用 |
| 郑商所席位：菜粕、菜籽油 | 2016-10-10 |
| 郑商所席位：花生 | 2021-02-01 |
| 大模型新闻投票 | 2026-10-26 起，观察期先不进训练 |

成交额 `amount` 不进特征。量用 `vol`，仓用 `oi`，这两个 CTP 实时就有。

## 4. 新闻

词数新闻已停，文章在 `archive/news-2026-10-27/`。不要再把「新闻倾向」「新闻三日」加回特征。

大模型投票在 `data/llm_poll/`，每天 14:40 问、不看盘。打算以后用净票代替新闻，但要等观察到 2026-11-26，用样本外验证赢过现役配菜再换。在那之前新模型也不要直接吃这些票。

## 5. 不要跑的脚本

`ingest/build_main_minutes.py` 已封死。再跑会用旧规则覆盖按日历拼好的主连。主连只由 `ingest/stitch_from_calendar.py` 重拼，并保留实盘尾盘。
